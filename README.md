# Autonomous AI Browser Agent (ReAct Pattern)

Проект представляет собой автономного AI-агента, способного решать многошаговые задачи в браузере без предварительно прописанных сценариев. Агент самостоятельно анализирует интерфейс, принимает решения и взаимодействует с элементами страницы в режиме реального времени.

## 🧠 Ключевые особенности реализации

* **ReAct (Reasoning + Acting) Framework:** Агент работает в цикле «рассуждение — действие — наблюдение». Он не просто выполняет команды, а анализирует состояние DOM перед каждым шагом.
* **Zero-Hardcode Approach:** * Никаких преднаписанных селекторов (Xpath/CSS-пути определяются моделью динамически через маппинг ID).
    * Никаких заготовленных планов действий (агент сам решает, как найти спам, оформить заказ или найти информацию).
* **Умная фильтрация контекста:** Собственный алгоритм извлечения интерактивных элементов (A, Button, Input, Select) позволяет работать с тяжелыми SPA-приложениями (например, Яндекс.Почта) в рамках лимитов контекстного окна LLM.
* **Provider Agnostic:** Модульная архитектура позволяет подключать любые модели (Gemini, GPT-4o, Claude 3.5) через унифицированный интерфейс провайдеров.

## 🛠 Технический стек

* **Python 3.10+** (Asyncio для высокой производительности)
* **Playwright** (Headless/Headful управление браузером)
* **Pydantic v2** (Строгая типизация ответов агента)
* **LLM:** Интеграция через OpenRouter (поддержка Gemini 2.0 Flash для высокой скорости инференса)

## ⚙️ Установка и запуск

1. **Клонирование и зависимости:**
   ```bash
   git clone [https://github.com/Sveagle/browser_ai_agent.git](https://github.com/Sveagle/browser_ai_agent.git)
   cd browser_ai_agent
   pip install -r requirements.txt
   playwright install chromium

```

2. **Конфигурация:**
Создайте `.env` на базе `.env.example`. Для работы агента необходим API-ключ (рекомендуется OpenRouter или Gemini).
3. **Запуск:**
```bash
python main.py

```



## 🎥 Демонстрация

Из-за требований безопасности и обработки персональных данных в интерфейсе почты, логика работы агента подробно отражена в логах терминала и архитектуре решения. Агент полностью автономен: от ввода логина до финального выполнения задачи.

## 📈 Направления для масштабирования

* Интеграция **Computer Vision** для анализа сложных графических интерфейсов.
* Поддержка **MCP (Model Context Protocol)** для расширения инструментов агента.
* Внедрение долгосрочной памяти (RAG) для запоминания предпочтений пользователя.
