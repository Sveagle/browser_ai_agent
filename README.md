# Autonomous Web AI-Agent

Экспериментальный автономный ИИ-агент, способный управлять браузером для выполнения сложных многошаговых задач без предварительно написанных сценариев.

## 🚀 Особенности

* **Zero-Shot Navigation**: Агент не использует захардкоженные селекторы. Он анализирует структуру страницы "на лету".
* **ReAct Loop**: Цикл "Рассуждение-Действие", позволяющий агенту корректировать свои шаги при ошибках.
* **DOM Compression**: Умная фильтрация элементов страницы для минимизации контекста и стоимости токенов.
* **SOLID Architecture**: Чистый код на Python с четким разделением ответственности.

## 🛠 Технологии

* **Language**: Python 3.10+
* **Automation**: Playwright
* **Intelligence**: Claude 3.5 Sonnet / GLM-4.6
* **DevOps**: Poetry, Flake8, Black, Isort
